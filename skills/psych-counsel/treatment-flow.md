# 处置方案详细指引

本文档为处置方案匹配阶段的详细参考。agent 在需要深入了解具体疗法时读取此文件。

## 处置方案检索策略

### Query 构建

基于诊断手册检索结果中的关键词构建处置方案 query：
- 格式：`{诊断主题} {推荐疗法} {具体技术} 治疗方案`
- 示例：`"焦虑障碍 CBT 认知重构 治疗方案"`
- 示例：`"情绪性进食 正念 进食觉察 指导"`

### 检索结果使用
- 优先使用 score ≥ 0.7 的处置方案
- 如果检索到多种疗法，根据用户状态选择最合适的
- 处置方案中的特殊要求（语气、流程、禁忌）必须优先执行

## 常用疗法参考

### CBT 认知行为疗法
适用场景：焦虑、抑郁、恐惧、成瘾行为等

核心步骤：
1. **识别自动思维** — 注意情绪波动时的想法
2. **评估思维证据** — 这个想法有什么支持证据和反对证据？
3. **认知重构** — 形成更平衡、客观的替代想法
4. **行为实验** — 尝试用新方式应对，观察结果

对话示例：
- "当你有这个想法时，身体有什么感觉？"
- "如果好朋友处在你的位置，你会怎么对他说？"
- "有没有另一种看待这件事的方式？"

### ACT 接纳承诺疗法
适用场景：慢性疼痛、广泛性焦虑、存在焦虑、成瘾

核心步骤：
1. **认知解离** — 与想法保持距离，"我注意到我有一个想法..."
2. **接纳** — 允许不舒服的感受存在，不试图消除
3. **接触当下** — 回到此刻的体验
4. **自我作为语境** — 观察-自我视角
5. **价值观澄清** — 什么对你真正重要？
6. **承诺行动** — 基于价值观的小步骤

对话示例：
- "你能不能只是注意到这个感受在这里，不需要推开它？"
- "如果这件事不会让你感到焦虑，你会选择做什么？"
- "对你来说，现在最重要的是什么？"

### 身体接地技术（5-4-3-2-1）
适用场景：焦虑发作、解离状态、创伤闪回、情绪过载

引导步骤：
1. "请环顾四周，告诉我你看到的 5 样东西"
2. "现在告诉我你能触摸到的 4 样东西"
3. "注意你现在能听到的 3 种声音"
4. "你现在能闻到的 2 种气味是什么？"
5. "注意你嘴里的 1 种味道"

### 呼吸稳定技术
适用场景：焦虑、恐慌、愤怒、入睡困难

**4-7-8 呼吸法**：
1. 用鼻子吸气 4 秒
2. 屏住呼吸 7 秒
3. 用嘴慢慢呼气 8 秒
4. 重复 3-4 个循环

**腹式呼吸**：
1. 一只手放在胸口，一只手放在腹部
2. 用鼻子缓慢吸气，让腹部像气球一样膨胀
3. 用嘴缓慢呼气，感受腹部慢慢回缩
4. 保持胸口基本不动

## 渐进式引导原则

1. **首次接触**：以建立关系为主，不急于引入技术
2. **探索阶段**：深入了解问题背景和用户需求
3. **引入技术**：在用户准备好时，逐步引入具体方法
4. **练习巩固**：鼓励用户在日常生活中练习
5. **反馈调整**：根据用户反馈调整方法

每次对话中，只聚焦 1-2 个技术点，避免信息过载。
