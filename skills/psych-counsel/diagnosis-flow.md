# 诊断流程详细指引

本文档为诊断检索阶段的详细参考。agent 在需要深入了解诊断流程时读取此文件。

## 诊断手册检索流程

### 1. Query 优化策略

基于意图分析结果构建高质量检索 query：

**基础 query 格式**：`{核心症状} + {持续时间/频率} + {影响程度}`

**优化技巧**：
- 使用专业术语的同义词扩展（如 "心情不好" → "抑郁情绪"）
- 加入鉴别诊断关键词（如 "排除躯体疾病"）
- 包含功能性影响描述（如 "影响工作" "社交回避"）

**Query 示例库**：

| 用户描述 | 优化后 query |
|---------|-------------|
| 最近总睡不着，心情很差 | "失眠 抑郁情绪 持续性 筛查" |
| 吃东西停不下来，吃完又后悔 | "情绪性进食 暴食行为 内疚感 评估" |
| 和谁都不想说话 | "社交回避 情绪退缩 人际隔离" |
| 工作压力大到喘不过气 | "工作倦怠 压力过载 焦虑症状" |
| 总觉得自己不够好 | "低自尊 完美主义 自我批评 认知评估" |

### 2. 检索结果处理

**高相关度（score ≥ 0.7）处理**：
- 直接参考手册中的评估维度和诊断标准
- 关注手册中提到的鉴别诊断要点
- 提取手册推荐的相关处置方案类型

**中相关度（0.5 ≤ score < 0.7）处理**：
- 作为补充参考，不作为主要依据
- 提取其中有价值的评估维度
- 与高相关度结果交叉验证

### 3. 诊断沟通原则

**应该做的**：
- 使用描述性语言而非标签性语言
- 表达不确定性："有些表现可能与...有关"
- 聚焦用户关心的具体问题
- 正常化：帮助用户理解这些反应的合理性

**不应该做的**：
- 直接给出诊断标签（如"你有抑郁症"）
- 使用 DSM/ICD 诊断编码与用户沟通
- 在信息不足时做出判断
- 忽视用户的自我认知和感受

### 4. 信息收集策略

在诊断评估过程中，自然地收集以下信息：
- **起病时间**：什么时候开始的？
- **持续时间**：持续了多久？是持续性的还是间歇性的？
- **触发因素**：有什么特别的事件或变化吗？
- **影响范围**：对工作/学习/社交/家庭有什么影响？
- **既往史**：以前有过类似的经历吗？
- **应对方式**：你通常怎么处理这些感受？
- **支持系统**：有可以倾诉的人吗？
