# 多维意图分析详细指引

本文档为意图分析阶段的详细参考。agent 在需要深入分析时读取此文件。

## 主题识别详细分类

### 情绪困扰
- 焦虑：过度担忧、紧张不安、预期性恐惧
- 抑郁：持续低落、兴趣丧失、无价值感
- 愤怒：易激惹、压抑愤怒、爆发性愤怒
- 恐惧：特定恐惧、社交恐惧、广泛性焦虑
- 悲伤：丧失相关、未解决的哀伤

### 人际关系
- 家庭关系：亲子冲突、代际沟通、家庭角色
- 职场关系：同事冲突、上下级关系、职场霸凌
- 亲密关系：沟通障碍、信任问题、分离/离婚
- 社交关系：社交焦虑、孤独感、归属感缺失

### 自我认知
- 自我价值：低自尊、冒充者综合征、完美主义
- 身份认同：性别认同、职业身份、人生阶段转变
- 存在意义：空虚感、目标缺失、存在焦虑

### 压力管理
- 工作压力：过劳、倦怠、职业发展焦虑
- 生活压力：经济压力、搬家、角色转变
- 学业压力：考试焦虑、学业倦怠、同辈压力

### 成瘾行为
- 饮食相关：情绪性进食、暴食、限制性饮食
- 物质相关：酒精、药物
- 行为成瘾：购物、游戏、社交媒体

### 躯体症状
- 睡眠障碍：失眠、嗜睡、噩梦
- 疼痛：慢性疼痛、紧张性头痛
- 疲劳：慢性疲劳、倦怠感

## 意图判断线索

| 意图 | 语言特征 |
|------|---------|
| 倾诉/宣泄 | "我就是想说..."、"没人能理解"、"太累了" |
| 寻求建议 | "我该怎么办"、"有什么办法"、"怎么改变" |
| 寻求诊断 | "我是不是得了..."、"这是什么病"、"正常吗" |
| 寻求陪伴 | "你在吗"、"陪我聊聊"、"不想一个人" |
| 求助干预 | "不想活了"、"控制不住"、"快要崩溃" |

## 心理状态评估细则

### 情绪强度分级
- **低**：日常烦恼，不影响日常功能
- **中**：明显困扰，部分影响工作/学习/社交
- **高**：严重困扰，显著影响多项生活功能
- **危机**：存在安全风险或急性心理崩溃

### 危机信号关键词
- 直接：自杀、不想活、结束生命、死、跳楼、割腕
- 间接：再也受不了了、没有意义、是大家的累赘、消失就好了
- 行为：遗言、赠送财物、突然平静（可能是决定后的解脱感）
