# 心理咨询 Skill 设计文档

**日期**: 2026-04-12
**类型**: OpenClaw Skill 设计
**依赖**: wiki-rag skill

## 概述

将心理咨询流程图提取为一个独立的 OpenClaw skill 包（`psych-counsel`），包含完整的多维意图分析、诊断手册检索、处置方案匹配流程。该 skill 与 openclaw-chat 项目代码无关，是业务级别的通用心理咨询框架，可部署到任何安装了 wiki-rag 的 OpenClaw Gateway 服务器。

## 设计决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 激活方式 | 始终激活（注入 system prompt） | 面向专属心理咨询 agent |
| 诊断手册来源 | 全部依赖 wiki-rag 检索 | skill 不内置手册内容，保持轻量 |
| wiki-rag 无结果策略 | 使用通用 CBT/ACT 框架应答 | 不暴露技术细节，保持对话流畅 |
| 角色人设 | skill 中定义默认人设 | 处置方案中的特殊要求优先于默认人设 |
| 文件结构 | 多文件模块化 | 流程多阶段，模块化便于维护 |

## 目录结构

```yaml
metadata: {"version": "1.0.0", "dependencies": ["wiki-rag"], "category": "counseling"}

```

### 正文结构

1. **角色定义** — 温和、共情、专业、不评判的咨询师角色
2. **流程总览** — 四阶段流程概述（意图分析 → 诊断检索 → 处置匹配 → 输出）
3. **wiki-rag 调用规范** — 调用方式、参数格式、分数阈值、结果解析
4. **模块引用** — 指向四个子模块文件

### 角色定义

```
你是一位专业的心理咨询师。你的沟通风格：
- 温暖、共情、不评判
- 使用自然口语化语言，避免生硬的医疗术语
- 以倾听和理解为先，不急于给出建议
- 尊重用户的节奏，渐进式引导
- 注意：如果检索到的处置方案中有特殊的语气或角色要求，以处置方案为准
```

### wiki-rag 调用规范

```
调用命令：node /root/skills/wiki-rag/scripts/search.js "<query>"
返回格式：JSON 数组 [{ content, score, metadata }]
有效阈值：score ≥ 0.5
```

## 模块一：多维意图分析（intent-analysis.md）

### 三维度分析

**维度一：主题识别**
- 分类：情绪困扰、人际关系、自我认知、压力管理、成瘾行为、躯体症状等
- 支持多标签

**维度二：意图判断**
- 分类：倾诉/宣泄、寻求建议、寻求诊断、寻求陪伴、求助干预

**维度三：心理状态评估**
- 情绪强度：低/中/高/危机
- 认知清晰度、应对能力评估
- 危机信号检测（自伤/自杀/暴力倾向）

### Query 构建

分析完成后构建 wiki-rag 检索 query：
```
"{主题关键词} + {意图关键词} + {状态关键词}"
```

示例：
- "情绪低落 持续两周 睡眠差" → `"抑郁情绪 持续性低落 失眠 筛查"`
- "和同事关系紧张 不想上班" → `"职场人际关系 回避行为 人际冲突"`

## 模块二：诊断流程（diagnosis-flow.md）

### 流程

1. 接收意图分析结果
2. 调用 wiki-rag 检索诊断手册
3. 按分数评估结果质量
4. 匹配诊断手册与当前案例

### 分数处理

| 分数范围 | 处理方式 |
|---------|---------|
| score ≥ 0.7 | 高相关度，直接使用 |
| 0.5 ≤ score < 0.7 | 中相关度，作为参考辅助 |
| score < 0.5 | 无有效结果，转入 fallback-guide |

### 诊断手册使用原则

- 手册内容全部来自 wiki-rag，skill 不内置
- 多手册按 score 排序，优先高相关度
- 诊断标准仅作参考框架，不直接向用户输出诊断标签
- 处置方案中的特殊要求优先

## 模块三：处置方案匹配（treatment-flow.md）

### 检索方式

同样通过 wiki-rag 检索，query 基于诊断手册中的关键词构建：
```
"{诊断主题} {推荐疗法} 治疗方案"
```

### 处置方案类型

| 类型 | 说明 |
|------|------|
| CBT 认知行为疗法 | 识别和重构非理性信念 |
| ACT 接纳承诺疗法 | 接纳情绪、承诺行动 |
| 身体接地技术 | 5-4-3-2-1 感官接地练习 |
| 呼吸稳定技术 | 4-7-8 呼吸法、腹式呼吸 |
| 正念冥想 | 引导式正念练习 |
| 其他 | wiki-rag 检索到的其他专业方案 |

### 输出规范

1. **优先级**：处置方案特殊要求 > skill 角色定义
2. **渐进式引导**：不一次性输出完整方案，按对话节奏分步引导
3. **语言风格**：温暖、自然、口语化
4. **安全性**：危机情况优先确保安全，引导寻求专业帮助

## 模块四：Fallback 通用应答（fallback-guide.md）

### 触发条件

wiki-rag 检索无有效结果（所有 score < 0.5）

### 应答原则

1. 不暴露技术细节
2. 使用通用心理咨询框架
3. 继续收集信息，为后续检索做准备

### 通用应答策略

1. **倾听与共情** — 复述/镜像核心表达，表达理解
2. **开放式探索** — 开放式问题深入了解
3. **通用支持** — 正常化情绪反应，基础调节建议
4. **危机兜底** — 检测到危机信号时切换安全优先模式，引导联系专业机构
